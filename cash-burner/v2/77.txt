## Bug 23 — engine_simple.py : _burst_ratio에서 trv5_prev=0일 때 burst가 거래대금 원금액
장 시작 첫 5초간 5~10초 구간에 틱이 없으므로 trv5_prev=0 → max(1.0, 0) = 1.0 분모
→ burst_ratio = trv5 / 1.0 = 수억~수십억 → burst_score 항상 20점 최대
→ 장 시작 직후 모든 종목이 burst 보너스 최대치로 진입 편향 발생.
```python
# 변경 전
def _burst_ratio(self, dq, now):
    trv5 = sum(px * vol for t, px, vol in dq if (now - t) <= 5.0)
    trv5_prev = sum(px * vol for t, px, vol in dq if 5.0 < (now - t) <= 10.0)
    return trv5 / max(1.0, trv5_prev)

# 변경 후 — trv5_prev=0 이면 비교 불가 → 1.0 반환
def _burst_ratio(self, dq, now):
    trv5 = sum(px * vol for t, px, vol in dq if (now - t) <= 5.0)
    trv5_prev = sum(px * vol for t, px, vol in dq if 5.0 < (now - t) <= 10.0)
    if trv5_prev <= 0:
        return 1.0  # 비교 기준 없음 → neutral
    return trv5 / trv5_prev
```
